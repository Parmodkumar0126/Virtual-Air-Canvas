# 🖐️ Virtual Air Canvas

An AI-powered virtual air canvas built with Python, OpenCV, NumPy, and MediaPipe Hand Landmarker.

The project uses real-time hand tracking to create an interactive futuristic interface controlled by hand gestures.

## ✨ Features

- 🖐️ Real-time AI hand tracking
- 🌐 Neon hand skeleton
- ✨ Aura effects
- 🟣 Interactive particles
- 🌐 Two-hand web effect
- 🕐 Real-time holographic clock
- 🎨 Air drawing
- 👆 Gesture-controlled mode selection
- 📸 Screenshot functionality
- 🔄 Reset mode
- 📊 Real-time FPS display

## 🛠️ Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Computer Vision
- Hand Gesture Recognition
